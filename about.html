Personal assistant on Telegram

DumE Assistant

A Telegram-based assistant designed to help organize tasks, reminders, notes and scheduled workflows.

What it can do

Depending on the features enabled in the bot, DumE Assistant can help manage a task list, remember useful instructions and project details, send scheduled messages, and analyze supported media. Important changes are intended to require your confirmation before they are made.

Google account connection

Telegram is the conversation interface. If you connect Google, the intended setup uses your own Google account for the assistant's app-related Sheet and Drive files. Google will show the permissions requested before you approve them. Do not approve a request that asks for access you do not expect.

The service is designed to keep each user's records separate, but the automation operator and the service providers needed to run the bot may process data. This is not end-to-end encryption and should not be treated as private from the operator.

Large-file uploads

The Telegram upload portal can prepare a Google Drive upload session and send a selected file to the Google account connected for that user. Check that you have connected the Google account where you want the file saved. The portal reports whether the upload was confirmed.

Important: free Gemini API and personal information

This version is planned to use the unpaid Gemini API for some AI replies or media analysis. Google's terms say content submitted through unpaid services may be used to improve Google products, may be reviewed by people, and should not include personal, confidential or sensitive information. Do not send private memories, personal details, passwords, health or financial information, or confidential work to a bot using the unpaid Gemini API.

Google's Gemini API terms also restrict API clients that are directed to, or likely to be accessed by, people under 18. Do not launch this version for under-18 users while it uses the Gemini API.

Read the Privacy Policy before connecting an account or uploading a file.
